# ADR 0002：採用零伺服器 `VS1.` 二維碼協定及 All Rights Reserved 版權保護

- **日期**：2026-11-04
- **狀態**：已採納（Accepted）

## 背景

1. **私隱與去中心化要求**：深資童軍紀錄冊包含未成年及青年成員之姓名、出生日期、聯絡電話、緊急聯絡人、地址及相片。成員與領袖在集會現場核簽時，不應強制建立雲端帳號，更不應將個人資料上傳至任何中央資料庫。
2. **成果保護要求**：專案作者明確要求**不採用 MIT 等寬鬆開源授權**，以防止任何外部機構（包括但不限於香港童軍總會或其附屬單位）在未獲授權下將 `SCOUT SYSTEM` 獨立研發之介面、程式碼與工具成果直接複製或據為己有；同時須清楚聲明本工具為非官方獨立工具，尊重香港童軍總會對訓練綱要與紙本紀錄冊文字之版權。

## 決策

1. **徹底移除後端 API，改用 100% 純前端 `VS1.` 二維碼與 URL Fragment 傳送**：
   - 成員出示二維碼時，預設不勾選任何欄位，由成員逐次剔選組別，經瀏覽器原生 `CompressionStream('gzip')` + Base64URL 編碼為 `VS1.<payload>`（環境不支援壓縮時自動退回 `VS1P.<payload>`），嚴格限制單張二維碼 `<= 2400` 字元以確保手機鏡頭秒讀。
   - 如需透過通訊軟件傳送唯讀快照，產生 `/#v=VS1...` 連結：瀏覽器規範保證 `#`（URL hash fragment）永不發送至伺服器，開啟時純在接收者本機解碼顯示。
   - 領袖掃描後一次手寫簽名並勾選核簽項目，產生輕量 `vsbook/signoff` 回傳二維碼，成員掃回即精準更新對應項目之日期、主考姓名與簽名墨跡。
2. **法務與版權雙重聲明**：
   - 根目錄 [`LICENSE`](../../LICENSE) 明訂 `Copyright © 2026 SCOUT SYSTEM — All Rights Reserved`，僅授予成員與領袖個人非商業前端使用許可，禁止未經書面授權複製、改作或據為官方成果。
   - 介面（`Legal.jsx`）與文件完整沿用 `ROVERBOOK` 非官方獨立工具中英聲明，明確區分軟件著作權（`SCOUT SYSTEM`）與訓練綱要內容版權（`香港童軍總會`）。

## 後果

- **正面**：零私隱外洩風險、零後端維護負擔、完全免登入即開即用，且版權歸屬與非官方邊界清晰無誤。
- **取捨**：單張二維碼無法同時塞入高解析近照與大量手寫墨跡，介面須即時顯示容量進度條並在超標時引導取消大圖或改用 JSON 備份檔傳送。
