# Out of Scope — 本專案明確不做事項

為保持 `VSBOOK` 輕量、離線可靠且私隱零外洩，以下功能明確排除於本倉庫之外（對齊 [`../../SCOPE.md`](../../SCOPE.md)）：

1. **全團名冊與雲端審批管理後台**
   - 不設團長管理全團 30+ 名成員進度之雲端面板。全團進度統計請使用姊妹專案 `vsbadge`（可由成員從 `VSBOOK` 匯出進度 JSON 交予領袖匯入 `vsbadge`）。
2. **團集會與訓練班教案庫**
   - 不內建集會活動流程設計或教案搜尋（屬姊妹專案 `vsmeeting` 範疇）。
3. **帳號密碼登入、雲端同步或中央資料庫**
   - 不收集電郵註冊、不接駁外部資料庫、不上傳任何個人資料或相片至伺服器。跨裝置轉移一律透過「匯出／匯入完整紀錄冊 JSON」完成。
4. **取代官方實體蓋印與簽批程序**
   - `VSBOOK` 生成之 `PT/65`、`PT/19`、`PT/20` 及紀錄冊內頁列印本，僅協助成員整齊填報及核對資料，正式遞交時仍須按香港童軍總會規定蓋上旅印、區印、地域印及由相關總監簽署。
